🔥 إعدادات Firebase

البيانات تُحفظ مباشرةً في Firebase Firestore.
لتغيير المشروع، افتح الملف وعدّل قيم firebaseConfig في أعلى الكود.

خطوات إعداد Firestore Rules (مطلوب):
1. افتح console.firebase.google.com
2. اختر مشروعك → Firestore Database → Rules
3. ضع القواعد التالية: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // السماح للجميع بالكتابة (إرسال التقييمات)
    match /feedback/{docId} {
      allow create: if true;
      allow read: if true;  // اجعلها false لتقييد القراءة على Dashboard
    }
  }
}
